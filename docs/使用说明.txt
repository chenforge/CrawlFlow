CrawlFlow 1.2 · Windows 64 位

启动
免安装版：解压到 D 盘或其他非 C 盘目录，双击 CrawlFlow.exe。
安装版：运行 CrawlFlow-1.2.0-Setup-x64.exe，默认目录 D:\CrawlFlow\App，也可修改。无需安装编程环境。
首次启动展示本地练习网站，点击“开始采集”即可体验 3 页、12 条文章。

采集自己的网页
1. 在“新建任务”填写网址，选择文章、链接、图片或表格。
2. 返回仪表盘，点击“自动识别”查看网页快照和字段。
3. 点击“测试规则”，确认结果后开始采集。
4. 先在数据预览中查看全部结果、搜索或清洗，再点击“保存到文件库”。
5. 需要交给其他软件时，选择导出 Excel、CSV 或 JSON。

文件库
点击侧栏“文件库”，可以查看已保存文件、搜索、改名、编辑单元格、删除记录。编辑后点击“保存修改”。删除记录后，在保存前可撤销。
删除文件会确认，并把恢复副本保留在 Data\Trash。恢复时关闭程序，将对应 JSON 文件移回 Data\Collections 后重新打开。
文件库保存的是可编辑的采集数据；导出的文件是独立副本，后续修改不会自动同步。

先预览，再保存
未保存结果只保留在本次运行内存中。退出或替换时会提醒保存；放弃后不能恢复。
历史记录保留最近 20 个任务的状态和设置。重启后，只有已保存的结果可以重新查看；其他任务仍能复用采集设置。
定时采集的结果也需要手动保存。已有采集在运行或还有未保存内容时，定时任务等待处理完毕。

数据位置
免安装版使用 EXE 旁边的 Data 文件夹。默认安装版使用 D:\CrawlFlow\Data。
Collections：文件库；Exports：Excel/CSV/JSON 和任务包；History：任务记录；Runtime：设置、网页登录与缓存；Trash：删除文件恢复副本。
安装在其他非 C 盘目录时使用该目录的 Data。若程序在 C 盘，则数据使用 D:\CrawlFlow\Data；没有 D 盘时，请将程序放到其他可写的非 C 盘。
首次升级会迁移旧版“轻采集”的有效历史、定时计划和登录资料；应用不会自动删除旧目录。新版卸载保留 Data。备份可复制整个 Data；更换电脑后可能需要重新登录网站。

高级模式
多数网站使用标准模式即可。高级模式支持 HTTP / HTTPS、UTF-8 / GB18030 / Big5 / Shift_JIS、超时、重试、浏览器标识和自定义请求头，也可关闭图片或音视频加载。
协议用于起始请求，网站仍可自行跳转。请求头每行“名称: 值”，只发往目标同源网站。Cookie、Authorization 等登录信息请在“打开网页 / 登录”窗口中设置。

点选与登录
在“采集规则”添加字段，命名后去网页点选。多个字段请选择同一条记录里的内容。
点击“打开页面”或“打开网页 / 登录”自行登录，再返回采集。默认自动找下一页，也可在分页设置中点选按钮。

其他功能
数据清洗：空格清理、空行移除、去重和文字替换，可撤销上次应用。
定时任务：每天或指定日期执行。需保持程序打开；关闭期间错过的单次任务不补跑。
任务共享：导出或导入 .crawlflow.json 规则包，包含高级设置，不包含网页登录凭据与采集结果。
Ctrl+K：搜索任务、功能和帮助。系统启用“减少动画”时，界面会减少动效。

范围
单任务最多 50 页、10000 条结果，访问间隔至少 1 秒。文章模板读取当前网页；完整正文可批量填写文章详情页网址。图片模板导出地址。复杂表格、无限滚动或特殊网站请先测试规则。
本版本尚未配置商业代码签名。
