CrawlFlow 1.1 · Windows 64 位免安装版

免安装版：解压后双击 CrawlFlow.exe。安装版：运行 CrawlFlow-1.1.0-Setup-x64.exe，按向导选择安装目录。无需安装编程环境。

第一次打开会展示随程序附带的本地练习网站。点击“开始采集”，即可体验 3 页、12 条文章的采集。

采集自己的网页
1. 在“新建任务”填写网址，选择文章、链接、图片或表格。
2. 返回仪表盘，点击“自动识别”查看网页快照和字段。
3. 点击“测试规则”，确认结果后开始采集。
4. 在数据预览中查看全部结果、搜索或选择记录，再导出 Excel、CSV 或 JSON。

点选内容与登录
在“采集规则”点击“添加字段”，命名后去网页点选。多个字段请选择同一条记录中的内容。
点击“打开页面”或“打开网页 / 登录”，在网页窗口完成登录，再返回采集。登录窗口与采集使用同一本机登录状态。
默认自动寻找下一页，也可以在分页设置中点选下一页按钮。

其他页面
数据清洗：清理空格、移除空行、去重、查找替换。可撤销上次应用；原始历史记录不受影响。
定时任务：支持每天或指定日期执行。请保持程序打开；关闭期间错过的单次任务不补跑，已有采集运行时等待空闲。
历史记录：保存最近20个正式任务，支持查看、复用设置和删除。预览不进入历史。
任务共享：导出或导入 .crawlflow.json 规则包，不包含网页登录状态与采集结果。
设置：调整采集间隔、等待时间、结果上限和去重。
Ctrl+K：搜索任务、功能和帮助。

升级后继续使用原来的本机数据目录 %APPDATA%\轻采集，保留原版历史与登录会话。

范围
单任务最多50页、10000条结果，访问间隔至少1秒。文章模板读取当前网页；需要详情正文时，可批量填写文章详情页网址。图片模板导出地址。复杂表格、无限滚动或特殊网页可能需要单独设置规则。建议先测试一页。

本版本尚未配置商业代码签名。
